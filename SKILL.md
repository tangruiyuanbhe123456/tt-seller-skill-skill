# TikTok Shop Seller Guide

## Quick Start
1. Register at shop.tiktok.com
2. Upload products with shoppable video
3. Set up affiliate program
4. Start live streaming

## Content Strategy
- 15-30 sec product demo videos
- Post 3-5 videos daily
- Use flash sales in live streams
- Train hosts on product knowledge
